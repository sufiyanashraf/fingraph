# FinGraph Lab

## Project Overview
FinGraph Lab is a modern financial calculator, graphing calculator, and mathematics learning tool combined into one product. The application must feel like a modern financial/mathematical learning tool.

## Technical Stack
- React + TypeScript
- Vite
- Tailwind CSS
- Plotly.js / react-plotly.js for interactive charts
- Math.js for equation evaluation
- Decimal.js for precise financial math
- Zod for validation
- Vitest for automated testing

## Core Features
1. Interest & Investment Calculator
2. Automatic Financial Growth Graph
3. Monte Carlo / Probability Simulator
4. Financial Growth Function Generator
5. Interactive Math Function Graphing
6. Basic Equation Calculator & Solver
7. Scenario Comparison
8. Goal Calculator
9. Math Challenge Game
10. Educational Explanations

Everything runs locally in the browser with localStorage persistence. No backend server or cloud dependencies for version 1.
