# FinGraph Lab Requirements

## Features
- **Dashboard**: Quick action cards, recent calculations using localStorage.
- **Interest Calculator**: Simple and Compound interest calculations with clear result presentation.
- **Investment Simulator**: Recurring investments with adjustable timing, inflation, and fee considerations.
- **Growth Graphs**: Interactive charts showing contributions, interest, and total value over time.
- **Growth Function Generator**: Mathematical representation of the user's investment growth.
- **What-If Simulator**: Side-by-side scenario comparison for exploring alternatives.
- **Monte Carlo Simulator**: 10th-90th percentile projections based on volatility and expected returns.
- **Graphing Calculator**: Interactive multi-function plotting.
- **Equation Solver**: Basic solver for linear and quadratic equations.
- **Goal Calculator**: Compute required time or contributions to meet a target.
- **Math Challenge**: Educational game with multiple difficulty levels and categories.
- **Learn Mode**: Step-by-step explanations for financial calculations.

## Non-Functional Requirements
- **Local Only**: All data stored locally (localStorage), no external APIs or backends for v1.
- **Responsiveness**: Mobile, Tablet, and Desktop optimized interfaces.
- **Validation**: Strict client-side validation to prevent bad inputs (e.g., negative years).
- **Architecture**: Clear separation of financial logic, math components, and React UI.
- **Testing**: Automated tests covering critical financial and math logic.
